# Redio

Мод Minecraft Forge 1.20.1. Сейчас собраны фаза 0 и прототип фазы 1. Полный плеер, коллекция, музыкальный блок и мультиплеер ещё не делаются.

Исходная концепция: `Yandex_Music_Minecraft_Technical_Spec.md`.

## Требования окружения

- JDK 17
- Интернет для первой загрузки Forge и Minecraft

## Команды

В терминале Cursor, из корня проекта `C:\code\self\yamod`. В Git Bash перед именем скрипта нужна точка и слэш.

Клиент одной командой. Скрипт сам находит Temurin 17, даже если в имени папки сменился номер версии. Системная Java может оставаться 8:

```text
./client.sh
```

`./gradlew runClient` открывает клиент Minecraft с модом. В игре клавиша `Y` открывает экран прототипа. Окно терминала не закрывайте, пока игра запущена.

## Токен

Пароль от аккаунта не нужен и не запрашивается. Токен не вставляется в исходный код.

Для живой проверки положите одну строку токена в файл:

```text
run/config/redio/token.txt
```

Этот путь относится к запуску из среды разработки. В установленной игре это `config/redio/token.txt` внутри каталога игры. Либо задайте переменную окружения `YANDEX_MUSIC_TOKEN`. Файл с токеном игнорируется git.

Как получить токен, описано в `docs/YANDEX_MUSIC_API.md`.

## Что умеет прототип

- Проверить, принимает ли сервис токен.
- Показать название и исполнителя первого любимого трека.
- Показать, отдан ли незашифрованный mp3.
- Воспроизвести такой mp3, поставить на паузу и остановить.
- Отдельно проиграть локальный тестовый тон, чтобы проверить паузу, стоп и освобождение звука без аккаунта.

Зашифрованный поток `encraw` мод не расшифровывает и не воспроизводит. Закрытие экрана звук не останавливает. Выход из мира и закрытие игры звук останавливают.
