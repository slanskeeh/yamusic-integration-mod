# Техническая спецификация

Статус: фазы 0 и 1. Полная концепция продукта лежит в `Yandex_Music_Minecraft_Technical_Spec.md` и этим файлом не отменяется.

## Платформа

- Minecraft Java Edition 1.20.1
- Forge 47.4.28
- Java 17
- `modid`: `yandexmusic`
- пакет: `dev.yamod.yandexmusic`
- версия мода: 0.1.0

## Что входит в текущую версию

1. Проект собирается из официального Forge MDK.
2. Мод загружается на клиенте и на выделенном сервере. На сервере нет аудио и нет обращений к Яндекс Музыке.
3. Клавиша `Y` открывает экран прототипа. Её можно переназначить в настройках управления.
4. Экран умеет проверить аккаунт, прочитать метаданные первого любимого трека и классифицировать аудиопоток.
5. Незашифрованный mp3 можно воспроизвести, поставить на паузу и остановить.
6. Локальный тестовый тон проверяет тот же жизненный цикл без сети.
7. Закрытие экрана не останавливает звук. Выход из мира и закрытие игры освобождают сессию.

## Что сознательно не входит

- Каталог, поиск, лайки, радио, очередь, перемотка.
- Фоновая музыка Minecraft.
- Музыкальный блок и мультиплеер.
- Расшифровка `encraw` и любой обход технической защиты.
- Хранение токена в исходниках, в сохранении мира или в конфиге Forge.

## Критерий честности

Если сервис не отдал незашифрованный поток, интерфейс говорит об этом прямо и не изображает воспроизведение. Пока живой трек внутри клиента не проверен на аккаунте владельца, фаза 1 не считается закрытой по критерию «подтверждено реальное воспроизведение».
