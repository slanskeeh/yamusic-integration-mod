# Фаза 0. Подготовка проекта

Сделать минимальный мод Forge для Minecraft 1.20.1 и Java 17.

## Объём

- Официальный MDK, зафиксированный Forge 47.x.
- `modid`, пакет и имя.
- Сборка `gradlew build`.
- Запуск клиента из Gradle.
- Начальные документы в `docs/`.

## Не делать

- Плеер, блоки, сеть, каталог.
- Секреты в репозитории.

## Приёмка

- Проект собирается.
- Клиент Forge видит мод.
- Версии записаны в `docs/DECISIONS.md`.
